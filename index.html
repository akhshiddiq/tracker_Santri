Pengelolaan Data

Kelola file cadangan website Monitoring Hafalan Santri RQ Al-Khansa. Ekspor untuk menyimpan cadangan, impor untuk menggabungkan data dari file JSON yang sesuai, dan gunakan Reset Riwayat hanya jika memang diperlukan.

Ekspor Data (JSON)

Ekspor membuat file cadangan berformat JSON dari data santri, riwayat, progres, dan pengaturan yang didukung website. Simpan file di tempat aman. JSON adalah format data, bukan laporan biasa.

Saran: buat cadangan sebelum impor atau reset riwayat.

Impor Data (JSON)

Impor membaca file cadangan JSON yang sesuai dengan format website. Data digabung berdasarkan ID; data dengan ID sama dapat diperbarui. File yang tidak sesuai akan ditolak.

Reset Riwayat

Fitur ini menghapus riwayat hafalan/catatan dan rekam jejak progres per level. Master santri, ID santri, kelas, pengaturan, serta kolom formulir Input yang sedang terisi harus tetap dipertahankan.

Tindakan ini dapat sulit dibatalkan. Ekspor cadangan terlebih dahulu.

Fungsi Simpan Input

Simpan Input digunakan untuk menyimpan setoran hafalan santri yang sedang dipilih, termasuk capaian ayat, progres surat, dan catatan ustadz. Setelah berhasil, data masuk ke Riwayat Input dan digunakan untuk memperbarui rekapan serta laporan sesuai mekanisme website.

Langkah selanjutnya

  1. Pastikan nama santri yang dipilih sudah benar.
  2. Periksa ayat awal, ayat terakhir, status hafalan, dan catatan ustadz.
  3. Klik Simpan Input satu kali dan tunggu pesan berhasil.
  4. Periksa Riwayat Input atau Rekapan untuk memastikan data tercatat.
  5. Untuk santri berikutnya, pilih namanya lalu periksa kembali isian sebelum menyimpan.

Keamanan data: tombol reset hanya mengosongkan isian formulir sementara. Progres dan riwayat yang sudah tersimpan tidak dihapus.
